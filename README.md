# My Obsidian Vault

A personal knowledge base for organizing study notes, learning resources, and day-to-day planning. This repository keeps the vault’s Markdown notes and Obsidian configuration together so they can be accessed and synced across devices.

## What’s inside

- **`Information Technolegy/`** — IT learning notes and reference material, including infrastructure, DevOps, Linux, security, and virtualization.
- **`networking/`** — Networking topics such as trunking and storage/network storage.
- **`LIFE/`** — Personal notes and reflections.
- **`To do list.md`** — A simple task list.
- **`.obsidian/`** — Obsidian vault settings and configuration.

> Folder and note names are kept as they currently appear in the vault.

## Open the vault

1. Install [Obsidian](https://obsidian.md/).
2. Clone or download this repository.
3. In Obsidian, choose **Open folder as vault** and select the downloaded repository folder.

You can also browse the `.md` notes directly on GitHub or edit them with any Markdown editor.

## Sync with Git

If you use Git to sync the vault, commit and push your changes after editing. On another device, pull the latest changes before continuing. Avoid editing the same note on multiple devices before syncing to reduce merge conflicts.

## Notes

This is a personal and evolving collection of notes. Content and organization may change over time. Check individual notes for their sources and context before relying on them.
